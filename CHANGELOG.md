# Changelog

## 1.0.0 — 2026-11-14

- First release.
- A custom slider replaces YouTube's volume slider in the watch page and embedded players.
- Volume curves: logarithmic (dB), power, linear, Bézier and custom points, with an interactive editor that has linear and dB views.
- Appearance options: width, track height, handle size, radius, colors, label, tooltip, collapse-on-hover, and presets.
- High-precision volume with smoothing, and YouTube's loudness normalization is kept.
- Mouse wheel and keyboard control (↑/↓ in the player), with an on-screen readout.
- Settings sync and apply live, with JSON export and import.
